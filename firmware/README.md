# 固件（ESP32-S3 侧）

这一侧的程序由 [Aily Blockly](https://yiyu.pro) 积木编程生成并烧录，不是手写 Arduino 工程。

## 文件说明

- `project.abi` —— Aily Blockly 工程源文件（积木结构快照），在 Aily Blockly 中可打开继续编辑

## 固件做了什么

1. 初始化 PCA9685（I²C 地址 0x40，PWM 50Hz），上电把 16 个通道归中 90°
2. 连接 WiFi（10 秒内连不上自动开热点 `ServoUnit` / 密码 `123456789`，配网页 `/setup`）
3. 启动 HTTP + WebSocket 服务（80 端口），串口 115200 打印本机 IP
4. 收到 WebSocket 文本消息 `通道:角度`（如 `0:142`）→ 解析 → 驱动对应通道舵机
5. 内置网页（`/`）提供 8 个滑块控制界面（与 PC 端脚本走同一条 WebSocket 通道）

## 通信协议（想自己写固件的人看这里）

不装 Aily Blockly 也可以用任意 Arduino/ESP32 方案自行实现固件，只需满足：

- WebSocket 服务端点：`ws://<板子IP>/ws`
- 接收**文本帧**：`"<通道>:<角度>"`，通道 0~15，角度 0~180（越界自动约束）
- 建议每秒重发一次各通道角度，防止舵机失锁

## 硬件与接线

- ESP32-S3 + PCA9685 16 路 PWM 板
- `3V3→VCC`、`GPIO8→SDA`、`GPIO9→SCL`、`GND→GND`（共地）
- 舵机电源接 PCA9685 绿色端子 `V+/GND`，**独立 5V ≥2A**，不要从 ESP32 取电

## 供电教训（踩过的坑）

舵机与逻辑电必须分离：VCC 走干净的 3.3V，V+ 走独立 5V，只共地。
否则舵机启动瞬间的电流尖峰会把 ESP32 拉到欠压复位（brownout 循环），
在 V+ 端子并一个 470µF 电解电容可以进一步吸收尖峰。
